## Installation

Clone the repository

```bash
git clone https://github.com/pragneshkalambe/DETTROIN-INT-Pragnesh-Website.git
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build the project

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
